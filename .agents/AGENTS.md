# Project Development Rules

## Execution Constraints
- **NO Build Runs:** Do not run `npm run build` or similar build command unless explicitly requested.
- **NO Type Checks:** Do not run `tsc`, typescript checking, or build-related type checks unless explicitly requested.
- **NO Browser Checks:** Do not run browser subagents or automated browser checks unless explicitly requested.
- **NO Git Command Runs:** Do not run `git` commands (e.g., git status, git diff, git commit, etc.) unless explicitly requested.
- **NO Explanations:** Keep responses extremely brief and direct. Just do what is asked with minimal to no explanation.
